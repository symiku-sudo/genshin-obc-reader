# 1.3.0 实施与验证

## 已确认的产品决策

五类任务均提供入口；覆盖率分阶段补齐。覆盖升级自动合并离线任务文本，优先保留本地较新或无法比较版本的正文。部分任务可以阅读并明确标缺。邀约按分支分段展示，不做交互路线图或剧透处理。按类型、来源地区、明确章节组织；只保留一个检查更新入口。来源限定观测枢，不以补齐所有历史文本作为发布条件。

## 实现

- `task_text.py`：来源标签、任务分类、正文白名单、稳定段落标识、显式对白图拓扑遍历、缺失说明；独立版本，不修改原有解析器版本 6。
- `catalog.py`：在任务目录中筛选五类，邀约使用明确标题前缀；多标签任务优先归入限时，保留所有原标签。六个未明确分类项目单独报告。
- `core.py`：补 `grams(entry_id)` 索引、单事务正文/索引/元数据写入、任务地区筛选、明确章节排序、空关键词浏览按词条聚合。
- `import_jobs.py`：两个受限下载线程、集中解析写库、完整更新检查、暂停恢复、限流重试；原始响应和检查结果与正文一起提交。
- `corpus_upgrade.py`：随包任务文本幂等合并，版本不明保留本地；中断后重试。完整本地正文不被部分随包正文替代。
- `static/`：地区筛选、不完整标识与清单、分组目录、分支跳转；新段落标识适配深链接和阅读记录备份。
- `prepare_android_assets.py`：从同一候选库生成首次安装库和升级补充包，不分叉两份内容来源。

## 本地可重复验证

```sh
python -B -m unittest -q
node test_reading.cjs
node test_v12.cjs
node test_v121.cjs
node test_v130.cjs
node test_android_bridge.cjs
python -B tools/benchmark_imports.py
```

联网 DOM 检查使用独立数据库副本和测试服务器，避免修改现用数据库：

```sh
OBC_TEST_URL=http://127.0.0.1:8767 node test_ui.cjs
```

性能原始记录位于忽略目录 `data/qa-v130/`。275 MB 旧库副本重写相同 30 个词条：补索引前 4.143 秒，之后 0.953 秒，下降约 77%；索引迁移本身约 0.924 秒。此结果只代表本地写入，不代表联网整轮导入。

`benchmark_imports.py` 使用明确标注的模拟网络延迟，分别验证首次导入与无变化更新。上游抽样响应仅提供 Cache-Control，未提供 ETag/Last-Modified，所以仍完整下载核对已有正文，避免漏掉修订。

## 文本库准备

```sh
python -B tools/fetch_task_sources.py
python -B tools/build_task_corpus.py
```

缓存、候选 SQLite 和覆盖报告均在 `data/` 忽略目录；现用数据库不被替换。目录样本及代表性页面保存在 `research/tasks/`，用于离线回归。

本机未安装 JDK、Gradle、Android SDK 或 adb；APK 构建与模拟器检查使用仓库既有 GitHub Actions。工作流新增候选文本包 Release 标签输入，支持独立候选分支构建。正式发布仍须使用验证成功的构建产物与原签名证书。

真实 1.2.1 → 1.3.0 覆盖安装、Android WebView 阅读与备份流程已通过 Android 35 模拟器验证；实体机表现及存储峰值仍待实测。

## 候选数据与当前验证结果

目录 1115 项：可分类 1109 项均已下载并生成可读文本，另有 6 项待分类。候选库共 4746 个词条、49592 段文本。任务中 891 项未检测出结构缺口，218 项保守标为不完整或待核对；这不表示已覆盖游戏中的全部原文。

| 魔神 | 50 | 23 |
| 世界 | 616 | 114 |
| 传说 | 92 | 24 |
| 邀约 | 19 | 19 |
| 限时 | 332 | 38 |

旧库副本升级：补入 1108 项，保留 1 项同版本原缓存；旧任务另外以本地原始响应做格式迁移，最终五类共 1109 项。已读记录前后完全一致，其他阅读数据存于 WebView，本实现不写其存储。合并 111.28 秒，重复检查 0.029 秒。旧任务原始响应与随包响应并不相同，因此保留本地来源，而非强行覆盖。

文本包解压 1042849792 字节，gzip 265597245 字节；升级补充包约 24 MiB。候选 APK 约 312.5 MiB；安卓安装空间峰值尚未实测。

后端 64 项测试；界面测试涵盖原有阅读、1.2、1.2.1、1.3.0 与安卓桥接；真实本地 HTTP 的 DOM 回归通过。Android 原生测试已更新到候选 manifest 数量，并新增五类离线任务、分支跳转及备份校验测试，已通过 Android 35 模拟器执行。

最终补充包校验：1109 个任务均有唯一段落标识，全部分支目标有效。已修复富文本转义内容二次解析造成的 4 个缺失跳转，并加入回归测试与构建前全量检查。
