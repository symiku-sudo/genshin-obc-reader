# 1.3.2

这版调整文库、划线和阅读页的布局与排版。

- 文库：紧凑的续读区域、文字列表；阅读状态与收藏筛选集中到筛选面板。
- 划线：原文优先，来源与分类置于下方；编辑和删除位于每条划线的“⋯”菜单。
- 阅读：统一标题、正文和段落间距，字号调节集中到“字号 Aa”。
- 统一米白与墨绿配色、按钮层级和触控尺寸。
- 同步安装包签名兼容处理：清理未签名构建元数据，保留原证书与 v1/v2/v3 签名。

使用原签名，可直接覆盖安装并保留阅读记录。这是正式版，1.3.1 的应用内更新检查会提示升级。已安装 1.3.2 试用版的用户，请从本页重新下载安装包覆盖安装。

### 划线尾标修复

恢复正文中笔记尾标原来的 20px 小方标，避免被全局按钮最小高度撑长。使用原证书，可直接覆盖安装；下载链接不变。
