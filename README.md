# 观测观测枢

原神中文文本的本地浏览与搜索网页。使用 Python 标准库和 SQLite，不需要账号或 npm 运行依赖。

首页提供自由浏览、全文搜索和“全部／未读／已读”筛选。可在列表或正文页手动标记词条已读；标记保存在 SQLite。收藏、阅读位置和字号保存在当前浏览器。管理区收纳目录导入、更新、在线查找及阅读记录备份。备份文件包含已读标记、收藏、位置和字号，不含正文；恢复会合并阅读标记与收藏，并保留当前已有的位置和字号。

当前已接入书籍、武器、圣遗物、地图文本、角色、食物、背包、月谕圣牌 8 类观测枢公开文本。实际覆盖取决于原站公开正文及当前提取规则；目录不代表游戏内全部文本。保存中文故事、设定、书籍、交互对白、物品描述及角色中文语音文案。属性、成长与突破材料表、配装攻略、图片、视频、音频和玩法数值不进入正文。对白结构异常或未知模块会标为待核对，避免猜测拼接。

## 1.3.0 候选开发版

新增魔神、世界、传说、邀约、限时五类任务；按来源地区筛选，按明确章节顺序浏览，支持分支跳转和离线搜索。正文不完整时展示缺失清单；部分邀约来源仅有结局短句，不代表完整对白。导入采用两个受限下载线程，补充索引并减少重复写入。

候选文本库包含 4746 个词条、49592 段文本，其中任务词条 1109 个，218 个标记待核对或不完整；目录另有 6 个类型不明确的词条未自动分类。版本升级自动合并随包任务文本，保留本地较新或无法比较版本的正文和阅读记录。旧版试读任务仅使用本地原始数据做分类与格式迁移，不重建原有八类文本。

当前为本地候选实现，尚未发布 1.3.0 APK。候选库解压约 995 MiB，压缩文本包约 253 MiB，升级补充包约 24 MiB；最终 APK 大小与安卓峰值空间仍待实际构建验证。首次升级在本机数据库副本上的合并约 111 秒，再次检查约 0.03 秒。

实现和验收范围见 [1.3.0 实施记录](docs/v1.3.0-implementation.md)。下方 1.2.1 下载链接仍指向已发布版本。

## 在 Termux 中运行

```sh
cd obc-reader
sh control.sh start
```

在同一台设备的浏览器打开 <http://127.0.0.1:8766/>。该地址只供本机访问。使用 `sh control.sh status` 检查服务，`sh control.sh stop` 停止。Android 结束 Termux 后需重新启动服务；导入任务会保存进度并可继续。

前台运行方式：

```sh
sh start.sh
```

## 缓存和隐私

所有下载的正文、搜索索引、阅读标记和数据库备份保存在 `data/`；该目录被 Git 忽略。不要提交个人的 SQLite 数据库或阅读记录备份。样本响应和目录清单位于 `research/`，用于测试与离线解析；它们包含观测枢文本，当前 GitHub 仓库设为私有。

`python audit_imports.py` 和 `python audit_map_cache.py` 可从本地缓存生成覆盖报告；`python recheck_saved_reviews.py JOB_ID [...]` 只用数据库已保存的原始响应重查待适配项，不联网。

## 独立安卓 App

[下载 v1.2.1 安装包](https://github.com/symiku-sudo/genshin-obc-reader/releases/tag/v1.2.1)
（私有仓库，需要登录有权限的 GitHub 账号）。下载 `obc-reader-1.2.1.apk` 后安装，
按系统提示允许当前下载工具安装应用。支持 Android 7.0 及以上的 arm64 / x86_64 设备。
首次启动会解压内置文本库，请稍等；无需联网下载。建议预留 1 GB 空间供安装和首次解压使用。

内置 3638 个词条、17511 个文本段落（含 22 张月谕圣牌）。浏览、全文搜索、筛选、已读、收藏、字号、
阅读位置、划线和阅读记录备份恢复均可离线使用；获取或更新观测枢文本需要联网。
从网页版迁移记录：网页「管理」导出 JSON 备份，再在 App「管理」选择备份并合并恢复。
备份包含阅读记录、划线和偏好，不包含正文数据库。更新请直接覆盖安装，勿先卸载。

1.2.1 使用原开发者证书，同时附带 v1/v2/v3 签名；针对 vivo 提示缺乏开发者证书增加
旧格式兼容，目标手机仍需实际确认。不要安装独立的根证书。

首页两个「继续阅读」入口保留最近两篇不同文本的位置。进度记录段落和字符位置，折叠/展开、调整字号后
按该字符所在行恢复；系统重建 Activity 时恢复当前词条。正文末尾可标记已读。
开启已读/未读筛选后，修改状态不会立即移除卡片，下次主动搜索、筛选或翻页才重新筛选。

长按选择正文，再点「划线」保存；顶部「划线」可查看列表、跳回原文或删除。划线纯本地
保存，可添加及再次编辑笔记，也支持 JSON 备份恢复；有笔记的划线末尾显示角标，点击划线或角标可编辑、删除。删除含笔记的划线会要求确认；正文更新后无法匹配的划线仍保留在列表中。

搜索可使用「＋」添加多个关键词，通过下拉菜单选择任一关键词（或）、全部关键词（且）或精确短语。
且模式在同一存储文本段落（连同词条与段落标题）内匹配全部关键词；或模式匹配任意关键词。
不设置关键词数量上限。最近 30 组搜索历史保留完整关键词及模式，可单项删除或清空。
选中正文可直接搜索；搜索页顶部浮空按钮可返回原文。打开结果时隐藏，回到搜索页后恢复；新一次划线搜索替换来源，只保留一个临时返回位置。点击返回或切换自由浏览后清除。笔记、双续读位置和搜索历史包含在 JSON 备份中，兼容旧备份。

安卓版本复用同一套页面、提取器与搜索接口，Python 通过 Chaquopy 运行在 App
进程内。没有监听端口，不依赖 Termux 或网页服务。内置当前完整中文文本库，
首次启动在 App 私有目录解压；升级不会覆盖已有数据库。已读记录保存在 SQLite，
收藏、位置和字号保存在 App 的 WebView 存储。网页已有的阅读记录可以通过管理区
导出 JSON，再在 App 中选择文件合并恢复。

构建需要 JDK 17、Python 3.13、Gradle 8.11.1、Android SDK 35。GitHub Actions
工作流下载私有 Release 中的文本包，并运行后端测试及模拟器断网验收。
签名密钥保存在 Actions Secrets，本地副本位于忽略目录 `data/android/signing/`；构建日志与 Git 不包含密钥。后续版本必须沿用
同一签名密钥及 applicationId，才能保留数据覆盖安装。

本地准备资产与构建调试包：

```sh
# 从当前网页数据库生成全量文本快照；不会修改原数据库
python tools/prepare_android_assets.py --snapshot
cd android
gradle :app:assembleDebug
```

已有文本包时使用 `python tools/prepare_android_assets.py`。
发布构建使用 `OBC_SIGNING_FILE` 指向 PKCS12 文件，`OBC_SIGNING_PASSWORD`
通过环境变量提供，别名为 `reader`。不配置签名时只能直接安装调试构建。

验收结果与测试范围见 [Android 验收清单](docs/android-parity.md)。
